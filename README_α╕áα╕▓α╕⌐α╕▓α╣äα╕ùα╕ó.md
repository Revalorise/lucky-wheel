# Wheel of Fortune สำหรับ Raspberry Pi 4 (ชุดกู้คืน)

ชุดนี้เป็นโปรแกรม Raspberry Pi เดิมที่พบใน Downloads พร้อมไฟล์ที่จำเป็นต่อการเปิดโปรแกรม ได้แก่ `predictions.json` จำนวน 60 รายการ, `wheel_pic.png` และระบบพิมพ์ใบคำทำนายผ่านเครื่องพิมพ์ ESC/POS USB กระดาษ 80 มม. พร้อมสั่งตัดอัตโนมัติ

## ติดตั้งบน Raspberry Pi OS

แตก ZIP แล้วเปิด Terminal ในโฟลเดอร์นี้ จากนั้นรัน:

```sh
chmod +x install_raspberry_pi.sh run_raspberry_pi.sh
./install_raspberry_pi.sh
```

หลังติดตั้งครั้งแรก ให้ออกจากระบบ Raspberry Pi แล้วเข้าสู่ระบบใหม่หนึ่งครั้ง เพื่อให้สิทธิ์กลุ่ม `lp` มีผล จากนั้นเปิดด้วย:

```sh
./run_raspberry_pi.sh
```

## เครื่องพิมพ์ USB

ต่อ STMicroelectronics POS80 ด้วย USB และเปิดเครื่องก่อนเริ่มโปรแกรม ระบบจะค้นหา USB printer ให้อัตโนมัติ พิมพ์ใบคำทำนายเป็นภาพภาษาไทยขนาด 80 มม. แล้วตัดกระดาษ หากตรวจพบหลายเครื่อง ให้รัน `lsusb` แล้วใส่ค่าใน `printer_config.json` ตัวอย่าง `vendor_id` เป็น `"0x0483"` และ `product_id` ตามค่าที่แสดงจริง

ถ้าพิมพ์ไม่ได้ ให้รัน `lsusb` และตรวจข้อความใน Terminal ห้ามเปิดเกมด้วย `sudo` เพราะไฟล์ที่สร้างจะกลายเป็นของ root

โปรแกรมเดิมกำหนด `USE_GPIO = True` และใช้หมายเลขขาแบบ BCM:

- วันจันทร์ GPIO 5
- วันอังคาร GPIO 6
- วันพุธ GPIO 13
- วันพฤหัสบดี GPIO 16
- วันศุกร์ GPIO 17
- วันเสาร์ GPIO 18
- วันอาทิตย์ GPIO 19
- ปุ่มหมุน GPIO 20

ปุ่มต่อแบบ pull-up: ขาหนึ่งเข้ากับ GPIO และอีกขาเข้ากับ GND หากยังไม่ได้ต่อ GPIO โปรแกรมจะพยายามเปิดต่อด้วยเมาส์และคีย์บอร์ด

## การควบคุมด้วยคีย์บอร์ด

- เลข 1–7: เลือกวันจันทร์ถึงวันอาทิตย์
- Space: กดค้างเพื่อหมุน และปล่อยเพื่อให้วงล้อหยุด
- Esc: ปิดโปรแกรม

## ขอบเขตของชุดนี้

นี่คือเวอร์ชัน Raspberry Pi เดิมที่เพิ่มการพิมพ์ USB ภาษาไทยแล้ว ไม่ใช่เวอร์ชัน macOS ล่าสุด จึงยังไม่มีระบบหลายภาษา การชำระเงิน Dashboard สถานะออนไลน์ หรือการควบคุมระยะไกล ระบบพิมพ์ต้องทดสอบกับเครื่องจริง เพราะ POS80 หลายโรงงานอาจใช้ USB Product ID และ endpoint ต่างกัน
